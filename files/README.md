# 🛡️ SENTIFY - AI Smart Chat Assistant
An intelligent browser extension that acts as a real-time "emotional and security filter" for online messaging platforms (Messenger & Zalo). Built as a 3-month student project, it aims to combat cyber scams, decode chat sentiment, and promote safer digital communication.
## Features
- **Real-time Scam Detection:** Automatically flags high-risk conversations and suspicious patterns to protect users from online fraud.
- **Sentiment & Intent Analysis:** Analyzes the sender's tone and underlying intent to provide instant emotional context.
- **Smart Interventions:** Features a unique "Chat Freeze" mechanism and pre-suggests safe, appropriate responses before you hit send.
- **Privacy-First Architecture:** Powered by lightweight **Small Language Models (SLMs)** running locally on your device—ensuring sensitive chat data never leaves your computer.

## 🛠️ Tech Stack
- **Frontend / Extension:** JavaScript, HTML/CSS, Web Extension APIs
- **AI / Core Engine:** Python, Local SLMs (Small Language Models), JSON-structured prompting
- **Automation / OCR:** Windows Accessibility API & OCR for secure text extraction
